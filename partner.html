Integration

接入方案与流程 五步上线，全程有支撑

STEP 1 · 申请接入

获取密钥

XPIN 分配 appKey / appSecret（沙箱 + 生产各一套），报备你的回调地址与出口 IP。

STEP 2 · 鉴权

API Key 签名

请求头携带 appKey 与签名，静态密钥、无需换取令牌，一次配置长期可用。

STEP 3 · 同步目录

拉取套餐

调用 /products/list 同步可售套餐，在你的平台自主定价、组织与展示。

STEP 4 · 下单开卡

创建订单

用户支付后调用 /order/create，带唯一 idempotencyKey，同步返回订单号。

STEP 5 · 回调交付

接收二维码

开卡完成后平台回调推送二维码，你据此生成 eSIM 交付用户；随后用量 / 续订随时可查。

Security & Reliability

安全与可靠

🔐

API Key + 签名

静态密钥 + HMAC 请求签名，配合时间戳窗口与 nonce 防篡改、防重放。

🛡

幂等安全

下单类接口以 idempotencyKey 保证重试不重复开卡，网络异常也不多扣费。

🔔

可靠回调

开卡结果异步回调并自动重投，直至你的系统确认接收，配合 IP 白名单保障来源可信。

🧱

数据隔离

每个账户仅能查询与操作自身订单与卡片，账户间数据互不可见。

🌐

沙箱环境

提供独立沙箱与测试套餐，联调不产生真实费用，验证通过再切生产。

🤝

联调支撑

提供接入文档、示例代码与技术支持，全程协助你顺利上线。
